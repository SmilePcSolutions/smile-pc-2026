# 🖥️ Smile PC Solutions (2026)

Site web moderne pour l'entreprise de dépannage informatique **Smile PC Solutions** à Moyeuvre-Grande.
Développé avec **Next.js 14**, **Tailwind CSS** et **Supabase**.

## 🚀 Technologies utilisées

- **Framework** : Next.js 14 (App Router)
- **Langage** : TypeScript
- **Style** : Tailwind CSS + Framer Motion (Animations)
- **Base de données** : PostgreSQL (via Supabase)
- **ORM** : Prisma
- **Emails** : Resend
- **Icônes** : Lucide React

## 🛠️ Installation & Démarrage

1. **Installer les dépendances** :
   npm install

2. **Configurer l'environnement** :
   Le projet utilise un fichier .env à la racine avec vos clés API.

3. **Lancer le serveur de développement** :
   npm run dev

   Ouvrez http://localhost:3000 dans votre navigateur.

## 🗄️ Commandes Base de Données

- **Mettre à jour la BDD** :
  npx prisma db push

- **Voir les données** :
  npx prisma studio
